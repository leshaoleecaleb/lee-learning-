# ☁️ AZ-900 Smart Prep Hub

A beginner-friendly study platform designed to help learners prepare for the **Microsoft Azure Fundamentals (AZ-900)** certification exam.

## 📖 About the Project

AZ-900 Smart Prep Hub brings essential study tools together in one place. It helps learners review Azure concepts, practise exam-style questions, organize their study schedules, and track their preparation progress.

This project is built as a practical web development learning project using HTML, CSS, and JavaScript.

## ✨ Features

### 📚 Study Materials
- Review key Azure Fundamentals concepts.
- Learn about cloud computing and Azure services.
- Explore Azure management and governance topics.

### 🧠 Study Buddy
- Choose an AZ-900 topic to study.
- Read simplified explanations of important concepts.
- Practise topic-based questions.
- Ask questions about common Azure concepts using the built-in study guidance.

### 📝 Practice Quiz
- Answer AZ-900 practice questions.
- Check your answers and review your results.
- Use practice sessions to identify topics that need more revision.

### 📅 Study Planner
- Add study tasks and select topics.
- Set target dates for your study activities.
- Track completed tasks.
- Save your study plan locally in your browser.

### 📊 Exam Readiness
- Review available quiz performance.
- Monitor study task completion.
- View preparation progress and revision recommendations.

### 💾 Local Progress
The application uses browser local storage to save supported study information on your device. Data is not automatically synchronized between browsers or devices.

## 🛠️ Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling and responsive layouts
- **JavaScript** — interactive features and application logic
- **Local Storage** — saving supported study progress in the browser
- **Git and GitHub** — version control and project hosting

## 🚀 Getting Started

### Requirements

You need:
- A computer with a modern web browser
- The project files
- Visual Studio Code (recommended)
- The Live Server extension for VS Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/leshaoleecaleb/lee-learning-.git
   ```

2. Open the project folder in Visual Studio Code.

3. Make sure the following files are in the project folder:

   ```text
   lee-learning-/
   ├── index.html
   ├── style.css
   ├── script.js
   └── README.md
   ```

4. Open `index.html` in VS Code.

5. Right-click the file and select **Open with Live Server**.

6. Use the website in your browser.

You can also open `index.html` directly in a browser, although Live Server is recommended during development.

AZ-900 Smart Prep Hub is an independent learning project. It is not an official Microsoft product and is not affiliated with or endorsed by Microsoft.
